# One year, us ♥

A cute, responsive anniversary page made with plain HTML, CSS, and JavaScript. There is no build step or dependency install. Open `index.html` in a browser to preview it, or publish it with GitHub Pages.

## Personalize it

1. Open `script.js` and replace `YYYY-MM-DD` in `RELATIONSHIP_START_DATE` with your anniversary start date, in that exact format. For example, 7 October 2025 is `2025-10-07`.
2. Open `index.html` and edit the letter, surprise message, and three timeline moments. Search for `THE BEGINNING`, `A FAVOURITE MEMORY`, and `TODAY & ALWAYS`.
3. Change the page title in the `<title>` element if you like.

The day counter includes the start date as day one. If you leave the date placeholder unchanged, the page displays a reminder where the count appears.

## Put it on GitHub Pages

1. Sign in to GitHub and create a new repository. If you want the page at `your-name.github.io`, name the repository `your-name.github.io`; otherwise choose any repository name.
2. Add `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root. You can use GitHub's **Add file → Upload files** option, or push these files from your computer.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Its URL appears in **Settings → Pages**. Open that link to check it, then share it.

If you change files later, commit the updates to `main`; Pages will publish them automatically.

## Files

- `index.html` — page content
- `style.css` — colors, layout, responsive design, and animations
- `script.js` — relationship date counter and surprise button

The Google Fonts link is optional; the page uses Georgia and Arial as local fallbacks when fonts cannot load.
